# Simple PC Manager

A lightweight, modern Windows system utility built with C# and WPF for monitoring processes, managing performance, and viewing system information.

---

## 🌟 Key Features

* **Process Management:** View active system processes, monitor resource usage, and terminate unresponsive applications.
* **System Insights:** Real-time display of core hardware metrics, user elevation state, and system details.
* **Modern UI & Themes:** Seamless light/dark theme switching based on your system preferences or manual choice.
* **Crash-Resistant Design:** Built-in unhandled exception logging and background task error recovery to ensure stable runtime.

---

## 🛠️ Built With

* **Language:** C#
* **Framework:** .NET / WPF (Windows Presentation Foundation)
* **Target OS:** Windows 10 / 11
